# MiniOS

Мини-система на ядре Linux (Debian 12) для флешки на 2 ГБ. Загружается прямо с флешки
и не трогает диск компьютера: ничего не форматируется и не устанавливается.
Внутри: рабочий стол XFCE, Firefox, GParted, ClamAV, тот же антивирусный движок, что в WinTweaker
(MiniGuard), инструменты восстановления (TestDisk, ddrescue, сброс пароля Windows chntpw, SMART).

## Как получить образ
1. Создайте на GitHub новый репозиторий и загрузите в него содержимое этой папки (с папками `.github`, `auto`, `config`).
2. Вкладка **Actions** -> **Build ISO** -> **Run workflow** (сборка идёт 20-40 минут).
3. После зелёной галочки откройте запуск и скачайте артефакт **MiniOS-iso** (внутри `MiniOS.iso` и контрольная сумма).
   Если в логе есть предупреждение «образ больше 1.6 ГБ», он не влезет на флешку 2 ГБ: уберите пакеты из
   `config/package-lists/minios.list.chroot` (например, `firefox-esr`).

## Как записать на флешку
Через **Rufus** (rufus.ie): выберите флешку и `MiniOS.iso`, при вопросе режима выберите **«Режим DD-образа»**.
Или через balenaEtcher. Флешка при записи полностью стирается (диск компьютера не затрагивается).

## Как загрузиться
Вставьте флешку, перезагрузите ПК и сразу жмите клавишу меню загрузки (обычно F11, F12, Esc или Del,
зависит от платы). Выберите флешку. Для старых плат подойдёт и обычный BIOS-режим, и UEFI.
Если UEFI не грузится, отключите Secure Boot.

## Что делать внутри
- Пользователь `user`, пароля нет, `sudo` без пароля. Раскладка: английская и русская, Alt+Shift.
- Ярлык **MiniGuard** на рабочем столе проверяет диски Windows (только чтение) и запускает ClamAV.
- Командой в терминале: `miniguard`, `miniguard --full`, `miniguard --clam`,
  `miniguard --quarantine` (переименует найденное в `*.quarantined`), `miniguard /путь/к/папке`.
- База ClamAV собирается в образ при сборке; обновить: ярлык «Обновить базу ClamAV» (нужен интернет).
- Всё изменённое в live-сессии пропадает после выключения, так что система каждый раз чистая.

## Проверка без флешки
В виртуальной машине (QEMU): `qemu-system-x86_64 -m 2G -cdrom MiniOS.iso`.
